# Requirements: DevBookmark / QuickNote Hub

## Overview
A lightweight developer dashboard to store, organize, and search code snippets, tech links, and quick project notes.

## Key Features
1. 📌 **Bookmark Management**: Add, view, edit, and delete developer links and code snippets.
2. 🏷️ **Tech Stack Tagging**: Categorize notes by technology (e.g., React, Laravel, PostgreSQL, Docker).
3. 🔍 **Instant Search**: Filter bookmarks by title, tag, or language.
4. 🌓 **Dark/Light Mode**: Toggle UI theme for comfortable coding sessions.

## Target User Stories
- As a developer, I want to quickly paste a useful code snippet so I can reference it later.
- As a developer, I want to tag my notes by framework so I can easily filter my resources.
