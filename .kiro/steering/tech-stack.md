# Tech Stack & Guidelines

- **Framework**: Next.js 15+ (App Router, TypeScript)
- **Styling**: Tailwind CSS
- **Components**: Functional components using modern React Hooks
- **Imports**: Use path aliases (`@/components/...`, `@/lib/...`)
- **Workflow**: Always follow spec-driven development using `.kiro/specs/`
- **Naming Rule**: Always prefix database helper functions with `db_` (e.g., `db_getUser`).
